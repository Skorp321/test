# YOLOv8n Detection TensorRT

Это приложение выполняет детекцию объектов с помощью YOLOv11n на Raspberry Pi 4, используя NCNN для оптимизации производительности.

## Установка

## Запуск

1. Запустите контейнер с доступом к камере:
```bash
docker compose up --build
```
* перед запуском убедитесь что у вас предоставлен доступ всем пользователям к монитору:
```bash
xhost +local:root
```

## Использование

- Приложение будет отображать видео с камеры с наложенными детекциями
- Для выхода нажмите 'q'

## Структура проекта

- `src/visualize/infer_trt.py` - основной файл приложения
- `Dockerfile` - файл для сборки Docker образа
- `docker-compose.yml` - файл для запуска приложения

# Приложение для автоматической разметки 

1. ## Запуск
```bash
python3 src/visualize/ref_points.py
```

## Использование:
В приложение нужно выбрать видео. На нужном объекте поставить точку

отдельный файлы.
